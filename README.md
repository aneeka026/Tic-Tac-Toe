# Tic-Tac-Toe Game Website
A simple and fun Tic Tac Toe game built using HTML, CSS, and JavaScript. Play against a friend in the browser!

# Built With
- HTML
- CSS
- JavaScript

# Features
- Two-player mode
- Win and draw detection
- Game restart option
- Simple and clean UI

# How to Play
1. Open the game in your browser.
2. Player 1 is X, Player 2 is O.
3. Take turns clicking on the cells.
4. The first to align 3 symbols wins!
